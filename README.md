gephgui-slint is a GUI App developed for the Geph VPN (https://github.com/geph-official), best for those who don't like the offical desktop WebUI.

Developed with Rust + Slint toolkit (https://github.com/slint-ui & https://slint.dev/) under GPLv3.

geph-slint-pkg contains the bash scripts to build MacOS and Windows version installer packages, and tracks Geph official's geph5 repository for updates.

No Linux support yet since I don't have a Linux environment and I'm not familar with the various release editions.
You can try clone and tweak the codes to build your own (the geph offical codes can be a good reference as well).

Currently the App is English version only, and l10n hasn't started (but in plan)
